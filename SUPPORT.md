# Torqvio Support

## Getting Help

### 📚 Documentation
- **[Documentation](https://docs.torqvio.com)** - Complete guides, API reference, and examples
- **[API Reference](https://docs.torqvio.com/api)** - Detailed API documentation
- **[FAQ](https://docs.torqvio.com/faq)** - Common questions and answers

### 💬 Community Support
- **[GitHub Discussions](https://github.com/torqvio/torqvio/discussions)** - Ask questions, share ideas, and connect with other users
- **[GitHub Issues](https://github.com/torqvio/torqvio/issues)** - Report bugs and request features (check existing issues first)

### 🏢 Premium Support
For Pro and Enterprise customers, we offer dedicated support:

- **Email**: support@torqvio.com
- **Response time**: Within 24 hours for Pro, 4 hours for Enterprise
- **Features**: Priority bug fixes, architecture reviews, dedicated Slack channel (Enterprise)

### 🔒 Security Issues
For security vulnerabilities, please **DO NOT** use public channels:

- **Email**: security@torqvio.com
- **PGP Key**: Available on request
- **Response time**: Within 48 hours

See our [Security Policy](./SECURITY.md) for details.

## Support Guidelines

### Before Asking for Help
1. ✅ Check the [documentation](https://docs.torqvio.com)
2. ✅ Search [existing issues](https://github.com/torqvio/torqvio/issues)
3. ✅ Search [discussions](https://github.com/torqvio/torqvio/discussions)
4. ✅ Check the [FAQ](https://docs.torqvio.com/faq)

### When Creating an Issue
- Use the appropriate issue template
- Include your environment details (OS, Node.js version, Torqvio version)
- Provide clear steps to reproduce bugs
- Include relevant code snippets and error messages

### Community Guidelines
- Be respectful and constructive
- Help others when you can
- Keep discussions on-topic
- Follow our [Code of Conduct](./CODE_OF_CONDUCT.md)
